# Admin panel

The admin panel is the operational interface for recruiters, HR managers, and administrators. It is responsible for moderation, analytics, user oversight, and vacancy management.

## Stack

- Next.js / React
- TypeScript
- Tailwind CSS
- Charting and analytics components

## Main pages

- Dashboard
- Users
- Vacancies
- Applications
- Analytics
- Settings

## Integration

The admin panel consumes the same backend API used by native clients, with role-based access and secure authentication.
