# Admin panel

Admin modulida loyiha boshqaruvi va rahbarlik funksiyalari ishlab chiqiladi.

## Admin vazifalari

- foydalanuvchilarni ko‘rish va boshqarish
- vakansiyalarni moderation qilish
- arizalarni ko‘rish va ko‘rib chiqish
- employer va company accountlarini boshqarish
- analytics va reportlar
- premium va subscription management
- system notificationlarni yuritish

## Suggested modules

- Dashboard
- Users
- Vacancies
- Applications
- Reports
- Billing
- Notifications
- Settings

## Tech stack

- React / Next.js yoki admin template
- REST API integration with Go backend
- JWT auth
- charts and analytics

## Notes

Bu faoliyat admin panel uchun boshlang‘ich skelet bo‘lib, keyinchalik real backend bilan to‘liq integratsiya qilinadi.
