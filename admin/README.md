# Admin panel

Admin panel — bu WorkHub platformasini boshqarish uchun mo‘ljallangan admin moduli. Bu bo‘limda HR, recruiterlar, team leadlar va menejerlar tizimni kuzatadi, userlar va vakansiyalarni boshqaradi.

## Admin functions

- userlar ro‘yxatini ko‘rish
- employer va company datasetini boshqarish
- vakansiya moderation
- arizalarni ko‘rib chiqish
- analytics va reports
- premium plan va subscription management
- notifications va system event tracking

## Recommended admin modules

- Dashboard
- Users
- Employers
- Vacancies
- Applications
- Analytics
- Billing
- Notifications
- Settings

## Suggested stack

- React / Next.js
- Tailwind CSS
- Recharts / Chart.js
- JWT auth
- REST API integration with Go backend

## Admin access flow

1. admin login
2. dashboard overview
3. filter by users, vacancies, or applications
4. review and take action
5. analytics report generation

## Notes

Admin panel boshlang‘ich version bo‘lib, keyinchalik real monitoring va RBAC (role-based access control) qo‘shiladi.
