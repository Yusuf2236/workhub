# Android mobile

Bu katalog Android mobil ilova uchun loyiha skeleti va yetarlicha umumiy dokumentatsiya uchun ajratilgan.

## Android product goals

- login / register flow
- jobs feed and search
- vacancy detail view
- apply button and status tracking
- resume upload and profile management
- messaging/chat support

## Recommended stack

- Kotlin
- Jetpack Compose
- Navigation Compose
- Material3
- ViewModel
- Repository pattern
- Retrofit / Ktor (optional)

## Suggested screens

- Splash
- Login
- Register
- Home
- Search
- Vacancy Detail
- Apply
- Resume
- Chat
- Profile

## Notes

Bu qism initial skeleton holatda bo‘lib, backend API bilan real integratsiya qilish bosqichma-bosqich amalga oshiriladi.
