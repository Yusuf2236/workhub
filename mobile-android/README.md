# Android mobile

Bu katalog Android mobil ilova uchun umumiy loyiha skeleti va bo‘limlarini o‘z ichiga oladi.

## Foydalanish holati

- Kotlin + Jetpack Compose
- login, dashboard, job list, profile, chat
- repository and viewmodel structure
- API client layer

## Recommended screen list

- Splash
- Login
- Register
- Home
- Search jobs
- Vacancy detail
- Apply form
- Resume upload
- Chat
- Profile

## Tech stack

- Kotlin
- Jetpack Compose
- Navigation Compose
- Material3
- Retrofit / Ktor (optional)
