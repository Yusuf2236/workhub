# Design system

The design system provides a consistent UI foundation across Android, iOS, web admin, and desktop.

## Principles

- modern
- trustworthy
- accessible
- mobile-first
- minimal but premium

## Color palette

```text
Primary: #1D4ED8
Secondary: #0EA5E9

Warning: #F59E0B

Background: #F8FAFC
Text: #0F172A
Muted: #64748B
```

- Inter / Poppins
- H1: 32px
- H2: 24px
- Body: 16px
- Caption: 12px
